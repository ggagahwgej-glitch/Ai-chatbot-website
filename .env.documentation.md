# Environment Variables

## Required Server-Side Variables (Never expose to frontend)
- `GROQ_API_KEY`: Your Groq API key for llama-3.1-8b-instant model.
- `SUPABASE_SERVICE_ROLE_KEY`: Supabase Service Role key for database operations.

## Required Client-Side Variables (Exposed via NEXT_PUBLIC_)
- `NEXT_PUBLIC_SUPABASE_URL`: Your Supabase project URL.
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`: Your Supabase Anon key.

## Example .env.local
```
GROQ_API_KEY=sk-your-groq-key-here
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
PORT=3000
NODE_ENV=development
```

## Security Note
- The Groq API key is ONLY used in `src/app/api/chat/route.ts` (server-side).
- It is NEVER sent to the browser or included in frontend code.
- Supabase Service Role key is ONLY used in server-side API routes.
